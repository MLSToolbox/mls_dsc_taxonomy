# Data Characteristics

**Identifier:** C500

This perspective addresses changes affecting intrinsic characteristics of the data, including changes in value distributions, relationships among variables, and semantic properties.

Some of these changes may result from row additions or removals; they are considered separately because their implications for ML pipeline evolution differ. Row Set changes concern which instances are included in the dataset, whereas Data Characteristics changes concern how the data behaves and the patterns it represents.
