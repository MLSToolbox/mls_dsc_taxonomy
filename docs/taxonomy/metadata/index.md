# Metadata

Differences in the **information that describes the dataset** as a whole, rather than in its content: where it comes from, under which terms it can be used, which language and modality it has, how it is split for training and evaluation, among others.

They mainly affect whether the dataset is suitable and reusable for a given ML task, and may require changes in the configuration, the evaluation or the validation of the pipeline.

This dimension contains a single change type, which is documented as one closed page.
