# Numerical Column Values (C322)

**Perspective:** [Column Characteristics](../perspectives/column-characteristics.md)

## Description

Changes affecting the values represented in a numerical column, including transformations of their scale or distribution.

## Examples

Examples include applying multiplicative factors, logarithmic transformations, normalization techniques (e.g., min–max scaling or standardization), or value perturbation for obfuscation purposes.

## Potential implications for ML pipeline evolution

Such changes may require adaptations in preprocessing steps, feature-scaling procedures, or model retraining.
