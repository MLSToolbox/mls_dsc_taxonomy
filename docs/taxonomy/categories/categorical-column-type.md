# Categorical Column Type (C311)

**Perspective:** [Column Characteristics](../perspectives/column-characteristics.md)

## Description

Changes affecting the data type of categorical columns.

## Examples

Examples include encoding categorical variables as Boolean values through one-hot encoding, or transforming categorical columns into numerical ones (and vice versa).

## Potential implications for ML pipeline evolution

Changes to column data types may require adaptations in data preprocessing, feature engineering, and model configuration, as different ML algorithms and pipeline components may rely on specific data representations.
