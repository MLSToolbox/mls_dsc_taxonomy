# Data value

Differences affecting **the values themselves**. While [Rows set](../rows-set/index.md) differences concern *which* instances are included in the dataset, data value differences concern *how their data vary*.

A missing value can appear in the place of a non-missing one, or vice versa; and, in general, a non-missing value can take the place of another non-missing one.
