# Extra row


## What changes

The dataset contains instances that are not present in the reference version.

## Pipeline implications

Modifies the instances available for training, validation or testing. The effect depends on what is added (see the [table of affected rows](../index.md)), for example outliers or duplicates.

## Typical adaptation

Data preparation procedures, sampling strategies, model retraining or evaluation processes.

See also: [Absent row](absent-row.md), [Horizontal fragmentation](../../../storage/fragmentation/horizontal.md).
