# Row Set

**Identifier:** C400

This perspective refers to changes affecting the set of rows that constitute a dataset. Changes to row ordering may affect pipelines that rely on positional access. Additions and removals modify the instances available for training, validation, or testing; their potential impact depends on the characteristics of the affected rows.
