# Fragmentation

Differences in how the data are stored. Despite being conceptually considered as a whole, a dataset can be **physically divided** either horizontally into subsets of rows, or vertically into subsets of columns (for example, into several files).

Fragmentation only concerns where the data are physically stored. The role each part plays (for example, training or test) belongs to [Associated metadata](../../associated-metadata.md), and the rest of the taxonomy describes the dataset **as a whole**, once its fragments are put together.
