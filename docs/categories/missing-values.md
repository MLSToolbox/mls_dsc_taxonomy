# Missing Values (C510)

**Perspective:** [Data Characteristics](../perspectives/data-characteristics.md)

## Description

Changes in the presence or absence of missing values, as well as modifications in their distribution patterns.

## Examples

Missing values may appear or disappear, or their distribution across the dataset may change.

## Potential implications for ML pipeline evolution

Changes in missing values may directly affect pipeline execution and require adaptations to data validation or cleaning components.
