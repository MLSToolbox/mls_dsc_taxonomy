# About

## The paper

This website accompanies:

> Abelló, A., Gómez, C., López, L., Ayala, C.: *A Taxonomy of Dataset Changes for Supporting Machine Learning Pipeline Evolution*. In: Product-Focused Software Process Improvement (PROFES 2026), LNCS 17339, pp. 1–9. Springer (2027). [doi:10.1007/978-3-032-45954-1_32](https://doi.org/10.1007/978-3-032-45954-1_32)

The taxonomy was developed following an inductive, iterative process (Kundisch et al., 2022) by analysing several versions of tabular datasets hosted on Hugging Face, and refined through expert discussion of the implications for ML pipelines.

## How to cite { #how-to-cite }

Please cite the paper above. If you reference this website or its data files, use the repository metadata in [`CITATION.cff`](https://github.com/MLSToolbox/mls_dsd_taxonomy/blob/main/CITATION.cff) (GitHub shows a *Cite this repository* button).
